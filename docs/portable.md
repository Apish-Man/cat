# 猫在 · Windows 便携版

将 ZIP 完整解压到一个文件夹，双击其中的 `CatMate.exe`。程序会从同目录的 `_internal` 加载运行库和猫咪素材。双击小猫打开小屋，右键小猫或托盘图标可退出程序。

更新时先退出小猫，将新版本解压到新文件夹后启动。默认存档位于 `%LOCALAPPDATA%\CatMate`，升级前可复制这个目录作为备份。使用自定义存档的用户可继续通过 `--data-dir` 指定原目录。

本包附带 `THIRD_PARTY_NOTICES.md` 和 `licenses`。源代码、完整说明和预览见 [CatMate 项目主页](https://github.com/Apish-Man/cat)。
