# 猫在 v1.2.0

这个 Windows x64 版本修复了小猫走路时腿部和轮廓的重影。裸猫和六套服装各有 24 帧步态，起步、转向和停下时也能保持轮廓清晰。正常走动目标为 60 Hz，可在右键菜单中切换到 30 Hz 省电模式。

## 下载与使用

1. 下载 `CatMate-v1.2.0-windows-x64.zip`，将它完整解压。
2. 双击 `CatMate\CatMate.exe`。双击小猫打开小屋，右键可调整大小、启动常用软件或退出。
3. 从旧版升级时先退出小猫，再把新版解压到新文件夹。默认存档沿用 `%LOCALAPPDATA%\CatMate`。

如需校验下载，在 PowerShell 运行 `Get-FileHash .\CatMate-v1.2.0-windows-x64.zip -Algorithm SHA256`，并与同名 `.zip.sha256` 附件中的值核对。
