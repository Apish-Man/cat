# 猫在 v1.3.0-alpha.1 · Apple Silicon 开发预览

这是 CatMate 首个可运行的 macOS 3D 预览。启动后，一只项目自制的橘猫会在桌面待机和散步。光标划过头部或轻点头部时，它会停下来回应。按住身体可拖动，松手后它会在新位置继续活动。猫旁边的空白处可以操作后方窗口。

菜单栏的猫图标提供找回、缩小、放大、省电模式和退出。重启时会恢复大小、省电选项与相对位置。Mac 偏好单独保存，Windows 用户可继续使用 [v1.2.0 便携版](v1.2.0.md)。

## 安装候选包

目标架构为 arm64。开发机为 Apple M4，系统为 macOS 27.2.1（26B131）。候选包使用本地 ad-hoc 签名，Developer ID 签名和 Apple 公证尚待完成。从互联网下载后，Gatekeeper 可能阻止首次启动。

1. 将 ZIP 和同名 `.sha256` 放在同一目录，在终端运行以下命令核对下载。
2. 解压 ZIP，打开其中的 CatMate.app。运行时可以从菜单栏退出。

```sh
shasum -a 256 -c CatMate-v1.3.0-alpha.1-macos-arm64.zip.sha256
```

## 验证范围

开发机已验证 arm64 导出、透明区首次点击、拖出原窗口后松手、后方文本输入、角色命中和窗口找回。四个动作在三个应用缩放档位上通过了 144 帧检查。M4 上待机和散步各测约十分钟，桌宠 CPU 平均分别为 3.33% 和 18.26%，物理内存占用约为 133 MiB 和 131 MiB。用 ⌘H 持续隐藏后，十秒短测 CPU 为 0.3%–0.4%，重新打开可恢复。运行和采样方法见[开发机验证记录](../validation/macos-v1.3.0-alpha.1.md)。

同一开发账户已验证解压、启动、退出和重启。独立账户首次安装、系统睡眠唤醒、混合 DPI 多屏热插拔，以及用鼠标逐项点选系统菜单栏弹出项列为后续验收项。最低支持系统版本尚待独立安装验证。本版以 GitHub 预发布草稿保存，供开发验证。
