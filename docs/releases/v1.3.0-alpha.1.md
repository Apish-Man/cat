# 猫在 v1.3.0-alpha.1 发布说明草案

**状态：规划中。** 这是首个 macOS 3D 技术预览的暂定版本号。目标平台为 Apple Silicon，首轮体验验收机为 Mac mini M4。发布日期、最低 macOS 版本和下载附件将在实机验证后确定。

## 这一版想让你体验什么

打开应用后，一只立体小猫出现在桌面上。放着不动时，它会待机、自己走一段，再停下来。轻抚它时有动作反馈；拖到屏幕另一边松手，它能从新位置继续活动。点击身体旁的透明区域，仍能操作后面的窗口。可以从菜单栏找回小猫或退出。

## 平台与升级

本次预览计划提供独立的 macOS arm64 应用和一只内置猫。Windows 用户继续使用 [v1.2.0 便携版](v1.2.0.md)。Mac 预览版单独保存偏好；已有猫爪币、装扮、工作记录及存档迁移不在首个预览的交付范围内。

窗口边缘行走与跳跃安排在下一阶段。可替换角色、更多自主动作、登录启动及多屏深度适配按[架构说明](../architecture.md)逐步验证。

## 发布前需要得到的结果

每项结果对应的开发工作包和验证环境见 [Mac 预览版实现方案](../implementation-v1.3.0-alpha.1.md)。

- 在另一用户环境启动导出的 arm64 应用，记录 macOS 版本、签名和公证状态，并据实补齐安装说明。
- 实测自主行走、摸头、拖动、透明区点击、菜单栏退出和角色找回。检验不同缩放下的命中位置与屏幕边界。
- 在 M4 上记录待机和走动各十分钟的 CPU、内存及能源影响，并检查睡眠唤醒后的位置与交互。正式说明列出实测数据和已知限制。
- 核对模型与动作的再分发许可。验收完成后再生成安装附件与 SHA-256，并将正式说明限定为该构建实际具备的功能。
