### 常驻性能

同一台 M4 接交流电，保持显示设置，依次测无桌宠、固定待机、连续散步三种场景。保留日常后台应用。测试副本使用导出的 release 主程序，用测试入口固定状态并计时。每组 top 采 60 个十秒区间，两组桌宠各有 59 个有效进程区间；另用 macOS 的 proc_pid_rusage 读取进程累计能量和唤醒计数。表中内存为 top 的物理内存占用。进程归属功率取自能量计数的差值，整机功耗需要单独测量。

### 候选包溯源

构建基线为 `da77db0c97f4b5487cb7ca2de788841440580479`。从干净克隆运行 tools/build_macos.sh，导出前后工作区均干净。ZIP 大小为 27,938,319 字节，SHA-256 为 `b3a2fa7fa7147e4a332784adb16e58f9c63972e7babf8140c7527d2bda4a948a`。从 GitHub 草稿重新下载两个附件，shasum 校验成功。解压后的主程序为 Mach-O arm64，codesign 深度严格校验通过，签名为 ad-hoc。otool 列出的动态库均位于系统目录，引擎许可和第三方归属已随应用内置。

从 GitHub 草稿下载的 ZIP 解压启动后，透明区点击令独立测试按钮从 0 变为 1。同时复测了猫身越界拖动（窗口原点由 (603, 44) 至 (700, 53)）、回到后方输入框读回 `catmate-qa` 和按 Esc 退出。相同摘要的解压副本在同一账户再次启动和退出成功。

**隐藏与恢复。** 让专用后方输入窗口保持前台，向桌宠发送 ⌘H，用系统窗口列表持续确认桌宠处于隐藏状态。十秒内五个有效的两秒进程 CPU 样本依次为 0.3%、0.4%、0.4%、0.4%、0.4%。重新打开应用后小猫恢复可见，再按 Esc 正常退出。早期只检查了一次窗口消失，焦点恢复时桌宠重新显示，混合可见状态的采样已排除。

当前点击穿透、菜单与输入捕获由 Godot 的 macOS 窗口接口提供。开发机回归通过的操作已能用该接口完成，本轮无需额外的 AppKit 扩展。
