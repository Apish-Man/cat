# Mac 预览版验收记录

2026-11-19 在 Apple M4、macOS 27.2.1（26B131）上验证。引擎为 Godot 4.7.2.stable.official.ed1daf0bf，使用 Compatibility 后端，启动日志识别为 OpenGL 4.1 Metal。设备连接交流电源。主测试窗口为 224 逻辑点，在当前显示设置下渲染为 448 × 448 像素。

| 检查 | 方法与结果 |
| --- | --- |
| 导出简模 | 使用同版本官方模板生成 arm64 应用，在编辑器外启动。简模演示时点击透明角落使后方按钮计数从 12 变为 13。拖出原窗口后，后方文本框读回 `catmate-qa`。 |
| 导出橘猫 | 在后方放置含按钮和文本框的独立 Qt 测试窗口。通过 Cua Driver 对橘猫透明区发送一次前台点击，计数从 0 变为 1。由猫身像素 (223, 290) 拖至原窗口外 (500, 300)，松手后窗口原点从 (1624, 152) 移到 (1797, 167) 点。随后选中测试输入框并读回 `catmate-qa`。 |
| 角色与菜单 | 真图形窗口测试 0.6、1.0、1.5 三档应用大小，覆盖四个动作与反复转向的 144 个姿态采样。采样命中区域内无透明点；简模通过相同的轮廓检查。菜单栏项目已注册；放大、找回及省电开关通过程序内调用验证。 |
| 行为与存储 | 固定种子下对比 30/60/120 Hz 轨迹，检查越界夹回、旧目标取消、轻抚、失焦、屏幕边界改变及模拟 600 秒长帧。偏好测试覆盖重启读回、非法范围、未来格式和损坏文件备份。几何替身验证 1×/2× 下的负坐标往返、缩放脚底锚点、断屏后窗口完全可见。三组失败数均为 0。 |
| Windows 回归 | 在本机运行原有 Python 单测，25 项通过。Windows 发布包仍为 v1.2.0。 |

### 安装与系统级待验收项

按本次安排，候选包仅在开发机验收。另一 macOS 用户首次解压和启动、Gatekeeper 对下载附件的实际提示、系统睡眠和唤醒后的输入恢复、物理混合 DPI 多屏热插拔留待后续。上表的应用大小变化、模拟长帧、模拟移除屏幕分别覆盖对应逻辑路径，物理环境结果待补。最低支持版本将在独立安装验收后确定。
