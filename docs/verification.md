- 业务逻辑：`python -m unittest discover -s tests -v`，13 项全部通过。覆盖购买原子性、重复拥有、库存消费、过饱限制、工作积分/小数进度、时薪调整、跨日拆分、离开和休眠暂停、专注一次性奖励、抚摸冷却、提醒、节日限领、损坏存档及重载。
- Qt 界面集成：`python tools/verify_ui.py`，通过。按钮导航、喂食购买、穿搭、开始上班、专注暂停/结束、毛线球重力反弹、屏幕边缘追逐目标可达、随机叼走、透明区域命中遮罩、保存后重载均检查。使用独立临时存档。

- Windows 桌面图标：实际调用得到 97 个图标边界，读取接口正常。多显示器不同缩放和第三方桌面未逐一验证。
