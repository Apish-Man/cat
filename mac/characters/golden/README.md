# 内置橘猫

本项目直接在 Godot 场景中制作了模型、材质和关键帧。猫身、腿和尾巴由基础网格组成，耳朵使用拉伸多边形。场景文件包含完整可编辑源数据，随 CatMate 分发。模型与动作均无外部素材依赖。

在 Godot 中打开 `cat.tscn`，通过 AnimationPlayer 预览 `idle`、`walk`、`petted` 和 `held`。Rig 下的腿、头部及尾巴节点用各自局部原点作关节；行走动画原地播放，由行为核心决定桌面位移。默认头朝画面右方，反向行走水平镜像。主场景使用正交相机，窗口内的脚底定位基准为宽度的 50% 和高度的 85.5%。

命中区域覆盖头与躯干内部。尾尖、胡须和腿部摆动时，边缘点击可落到后方窗口。修改体型或相机后，使用 desktop_test.gd 在各档缩放、朝向和动作下对照渲染透明度。
